# sql-data-warehouse-project
Building a modern data warehouse with SQL Sever, including ETL processes, data modelling, and analytics.

This is a .md (Markdown) file which is generally use for to write details about the project so that if other people come see the code then they may understand what is the purpose of this project and what going to be achive with this project.

# Steps to create this Data-warehouse
##Step1: Check the init_database.sql file where script is given to create Database and Schema for all three layer bronze, silver and gold.
##Step2: Check the bronze folder where DDL command is given to create all six bronze layer table and In the second file script present to 
       load data from csv file to bronze tables.
##Step3: Check the silver folder where DDL command is given to create all six silver layer tables and In the second file script present that
       clean and transform data and load into silver layer tables.
##Step4: Check the gold folder where view created and store depending upon business logic and joined tables.
